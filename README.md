# LedgerPro downloads

Installers for **LedgerPro**, double-entry bookkeeping for small businesses.

**[Download the latest version](../../releases/latest)**

- **Windows 10/11:** `Setup_LedgerPro.exe`. If Windows shows "Windows protected your PC", click *More info* > *Run anyway*.
- **Linux:** `LedgerPro-linux-x86_64.tar.gz`. Unpack it and run `./install.sh`.
- **User manual:** `LedgerPro-User-Manual.pdf`.

LedgerPro checks this page for new versions and updates itself. Each release lists SHA-256 checksums in
`SHA256SUMS.txt`, which LedgerPro verifies before installing.

Your books are stored on your own computer (or a folder you choose), never here.
